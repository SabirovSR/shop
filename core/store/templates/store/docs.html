Документация API Магазина Книг

Это API предоставляет доступ к данным о авторах, книгах, категориях и отзывах.

Базовый URL

http://127.0.0.1:8000/api/v1/

Конечные точки

  • Авторы: /authors/ (GET, POST), /authors// (GET, DELETE)
  • Книги: /books/ (GET, POST), /books// (GET, PUT, PATCH, DELETE)
  • Категории: /categories/ (GET, POST)
  • Отзывы: /reviews/ (GET, POST), /reviews// (DELETE)
  • Отзывы к книге: /books//reviews/ (GET)

Примеры запросов

Получить список авторов

GET /api/v1/authors/

Создать нового автора

POST /api/v1/authors/ Content-Type: application/json { "name": "Имя Автора", "email": "author@example.com", "bio": "Биография автора", "birth_date": "1990-01-01" }

Получить книгу по ID

GET /api/v1/books/1/
